01 ABOUT THE PROJECT

关于计划

VoidenMedia（虚空影视）是 CreatiVoiden 正在进行的影像计划。我们不急着给它下定义，只想把脑海里的画面拍下来、做出来，再一点点修正。

从短片、视觉实验到网页与工具，所有尝试都会留在这里。它可能不会很快完成，但会一直生长。

02 WHAT WE DO

我们在做什么

不把自己限制在一种媒介里。影像、视觉与代码，都是把想法做出来的方式。

01 / FILM

影像制作

短片、纪录与实验影像。先把画面拍下来，再慢慢想它到底是什么。

02 / VISUAL

视觉设计

画面、包装与视觉风格。让每一帧都更接近脑海里的样子。

03 / CODE

创意开发

把想法做成网页、工具和小实验。代码也是表达的一部分。
